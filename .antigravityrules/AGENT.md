# Project Environment & Constraints
- Package Manager: `uv`
- Python Environment: Run all tasks within `uv run` or use the virtual environment at `.venv`
- Rules: All dependencies (like `customtkinter`) are already installed via `uv`. Do NOT try to run `pip install` or modify `pyproject.toml` / `requirements.txt`.
- GUI Framework: `customtkinter` (do NOT use standard `tkinter` widgets unless explicitly required).
- GUI Logic: All GUI logic are inside gui.py.
